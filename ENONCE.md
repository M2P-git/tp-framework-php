# Séance 01 : Laravel, Atelier Solidaire

L'accueil veut la liste des interventions ouvertes. Dans cette version, `clos` est le seul état exclu.
1. Écrire le scénario et trois critères dans REPONSES.md.
2. Retrouver la route, le contrôleur et la vue avec l'IDE.
3. Compléter `CatalogueInterventions::ouvertes` en conservant les éléments non clos.
4. Lancer les tests ; expliquer le résultat et le cas d'un dossier absent.
5. Décrire ce que Laravel apporte autour de la règle PHP.
Quiz : qui exécute PHP ? Quel composant choisit l'action ? Pourquoi `{{ }}` plutôt que du HTML brut ?
